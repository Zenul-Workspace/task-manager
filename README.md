# 📝 Python Task Manager

A lightweight, console-based Task Manager application built with Python. This project allows users to efficiently organize, track, and persist their daily tasks directly from the command line using local JSON storage.

## 🚀 Features

* **Add Tasks:** Create new tasks with custom names and statuses.
* **View All Tasks:** Display an organized, numbered list of all active tasks.
* **Update Status:** Easily modify the progress or status of any existing task by its index.
* **Delete Tasks:** Remove unwanted or completed tasks from your list.
* **Search Tasks:** Quickly find a specific task and its index number by name.
* **Data Persistence:** Automatically saves and loads your task data using a local `tasks.json` file so you never lose your progress.
* **Error Handling:** Robust input validation to handle incorrect menu choices or missing files gracefully.
